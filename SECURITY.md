# Security and wrong advice

## Reporting a vulnerability in the site

Please **don't open a public issue**. Use GitHub's private vulnerability
reporting ("Security" tab → "Report a vulnerability") on this repository.
We aim to respond within 7 days.

## Reporting wrong or dangerous advice

If a guide gives advice that could put someone at risk (for example, a step
that weakens security or exposes personal data), treat it as a security issue:
report it privately the same way, so it can be fixed before it spreads.

Outdated menu names or small mistakes can go in a normal issue using the
"Content correction" template.
