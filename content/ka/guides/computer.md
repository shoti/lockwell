კომპიუტერში ინახება თქვენი დოკუმენტები, ფოტოები და ბრაუზერი, რომლითაც ანგარიშებში შედიხართ. ეს გზამკვლევი განკუთვნილია Windows 11-ისა და macOS-ის მიმდინარე ვერსიებისთვის. პირველ ორ **აუცილებელ** ნაბიჯს დაახლოებით ათი წუთი დასჭირდება. მესამე ნაბიჯი — დისკის დაშიფვრა — თქვენს ფაილებს კომპიუტერის მოპარვის შემთხვევაში დაიცავს, თუმცა ყურადღებით წაიკითხეთ ინსტრუქცია: აღდგენის გასაღების დაკარგვა შეიძლება ფაილების სამუდამოდ დაკარგვას ნიშნავდეს.

## ჩართეთ ავტომატური განახლებები {#updates .essential}

განახლებები ასწორებს უსაფრთხოების იმ სისუსტეებს, რომელთა შესახებაც თავდამსხმელებმა უკვე იციან. Windows-სა და macOS-ს განახლებების ავტომატურად დაყენება შეუძლიათ — გადაამოწმეთ, რომ ეს ფუნქცია ჩართულია, და მოთხოვნისთანავე გადატვირთეთ კომპიუტერი. სისტემა, რომელიც უსაფრთხოების განახლებებს აღარ იღებს, დაუცველი რჩება საყოველთაოდ ცნობილი თავდასხმების წინაშე.

### Windows

1. გახსენით **Start → Settings → Windows Update**. თუ განახლებები ხელმისაწვდომია, დააჭირეთ **Download & install**-ს და მოთხოვნისას გადატვირთეთ კომპიუტერი.
2. Windows განახლებებს ავტომატურად აყენებს. მათი დროებით შეჩერება ერთ ჯერზე 35 დღემდე შეგიძლიათ (ვადის გაგრძელების შესაძლებლობით). უსაფრთხოების განახლებებს უმიზეზოდ ნუ დააპაუზებთ, ხოლო თუ შეაჩერეთ, რაც შეიძლება მალე განაახლეთ.
3. **Windows 10**-მა უსაფრთხოების განახლებების მიღება 2025 წლის 14 ოქტომბერს შეწყვიტა. თუ თქვენს კომპიუტერს Windows 11-ის მხარდაჭერა აქვს, გადადით მასზე. წინააღმდეგ შემთხვევაში ჩაერთეთ გახანგრძლივებული განახლებების პროგრამაში ([Extended Security Updates](https://www.microsoft.com/en-us/windows/extended-security-updates)) მენიუდან: **Settings → Update & Security → Windows Update → Enroll now** — ასე უსაფრთხოების განახლებებს 2027 წლის 12 ოქტომბრამდე მიიღებთ (საჭიროა Windows 10-ის 22H2 ვერსია და Microsoft-ის ანგარიში).
4. თუ კომპიუტერზე Windows 11 არ ყენდება, კიდევ ერთი გამოსავალი უფასო ოპერაციული სისტემა Linux-ია. დამწყებთათვის Privacy Guides რეკომენდაციას Fedora-ს უწევს. Fedora-ს თითოეული ვერსია განახლებებს დაახლოებით ერთი წლის განმავლობაში იღებს, ამიტომ ახალი ვერსიის გამოსვლისას სისტემა განაახლეთ. როგორც Privacy Guides აღნიშნავს, Linux-ით თავს აარიდებთ მონაცემთა იმ შეგროვებას, რაც Windows-სა და macOS-ს ახასიათებს, თუმცა Linux-ს აკლია უსაფრთხოების ზოგიერთი მექანიზმი — მაგალითად, აპლიკაციების მკაცრი იზოლაცია (Sandboxing). სისტემის დაყენებამდე აუცილებლად შექმენით ფაილების სარეზერვო ასლი: იხილეთ [შექმენით კომპიუტერის სარეზერვო ასლი](/guides/backups/#computer-backup).

### Mac

1. გახსენით **Apple menu → System Settings → General → Software Update**.
2. **Automatic Updates**-ის გვერდით დააჭირეთ ინფორმაციის ღილაკს და ჩართეთ **Download new updates when available**, **Install macOS updates** და **Install Security Responses and system files**.
3. Apple გირჩევთ გამოიყენოთ macOS-ის უახლესი ვერსია, რომლის მხარდაჭერაც თქვენს Mac-ს აქვს. თუ **Software Update** უფრო ახალ ვერსიას აღარ გთავაზობთ, შესაძლოა თქვენს მოდელზე ის აღარ ყენდებოდეს.

> [!warning]
> თუ თქვენი კომპიუტერი უსაფრთხოების განახლებებს აღარ იღებს, მოერიდეთ მასზე ელფოსტის, ინტერნეტბანკისა და სხვა მნიშვნელოვანი ანგარიშების გამოყენებას და დაგეგმეთ მისი გამოცვლა.

## ჩაკეტეთ ეკრანი, როდესაც კომპიუტერს ტოვებთ {#screen-lock .essential}

განბლოკილ კომპიუტერთან მისულ ნებისმიერ ადამიანს შეუძლია ნახოს თქვენი ელფოსტა, ფაილები და შენახული პაროლები. დააყენეთ ეკრანის ავტომატური ჩაკეტვა უმოქმედობის რამდენიმე წუთში, ხოლო კომპიუტერიდან გასვლისას ეკრანი თავადაც დაბლოკეთ.

### Windows

1. გახსენით **Start → Settings → Accounts → Sign-in options** და გამართეთ **Windows Hello**: PIN-კოდი, თითის ანაბეჭდი ან სახის ამოცნობა.
2. გადადით **Settings → System → Power & battery → Screen, sleep & hibernate timeouts**-ში და პარამეტრებში **Turn my screen off after** და **Make my device sleep after** მიუთითეთ რამდენიმე წუთი.
3. **Sign-in options**-ში გადაამოწმეთ, რომ ძილის რეჟიმიდან გამოსვლისას Windows ხელახლა ავტორიზაციას ითხოვდეს.
4. ეკრანის ხელით ჩასაკეტად კლავიატურაზე ერთდროულად დააჭირეთ **Windows**-ის კლავიშსა და **L**-ს.

### Mac

1. გახსენით **Apple menu → System Settings → Lock Screen**.
2. პარამეტრში **Require password after screen saver begins or display is turned off** აირჩიეთ მინიმალური დრო.
3. დააყენეთ ეკრანის გამორთვა უმოქმედობის რამდენიმე წუთის შემდეგ — როგორც ელემენტზე მუშაობისას, ისე კვების წყაროზე მიერთებისას.
4. **Users & Groups**-ში ნუ ჩართავთ ავტომატურ შესვლას (Automatic login), რადგან ნებისმიერს შეეძლება Mac-ის გადატვირთვა და სისტემაში შესვლა.

## დაშიფრეთ დისკი და შეინახეთ აღდგენის გასაღები {#disk-encryption .recommended}

დისკის დაშიფვრა თქვენს ფაილებს წაუკითხავს ხდის ყველასთვის, ვინც კომპიუტერს მოიპარავს ან მყარ დისკს ამოიღებს. აღდგენის გასაღები (Recovery key) დაგჭირდებათ მაშინ, თუ Windows ან macOS მის შეყვანას მოგთხოვთ — მაგალითად, კომპიუტერის ნაწილის შეცვლის შემდეგ ან პაროლის დავიწყებისას. დაკარგულ გასაღებს ვერც Microsoft აღგიდგენთ და ვერც Apple. დაშიფვრის ჩართვამდე წინასწარ გადაწყვიტეთ, სად შეინახავთ გასაღებს, და მისი ასლი აუცილებლად კომპიუტერისგან განცალკევებით იქონიეთ.

### Windows

1. შედით სისტემაში ადმინისტრატორის ანგარიშით და გახსენით **Settings → Privacy & security → Device encryption**. თუ ეს პარამეტრი ხელმისაწვდომია, ჩართეთ (**On**). თუ ის არ ჩანს და გაქვთ Windows Pro, გამოიყენეთ **BitLocker**: Start-ში ჩაწერეთ BitLocker და აირჩიეთ **Manage BitLocker → Turn on BitLocker**.
2. თუ სისტემაში Microsoft-ის ანგარიშით შედიხართ, შესაძლოა Windows-მა დაშიფვრა უკვე ჩართო და გასაღები თქვენს ანგარიშზე შეინახა. გადაამოწმეთ მისამართზე [aka.ms/myrecoverykey](https://aka.ms/myrecoverykey).
3. დამატებითი ასლის შესანახად Start-ში ჩაწერეთ BitLocker, აირჩიეთ **Manage BitLocker → Back up your recovery key** და გასაღები ამობეჭდეთ ან USB-მეხსიერებაზე ჩაწერეთ. შეინახეთ ის კომპიუტერისგან ცალკე.

### Mac

1. გახსენით **Apple menu → System Settings → Privacy & Security → FileVault** და ჩართეთ **FileVault**.
2. აირჩიეთ დისკის განბლოკვის მეთოდი პაროლის დავიწყების შემთხვევისთვის: თქვენი iCloud-ის ანგარიშით ან აღდგენის გასაღებით, რომელსაც თავად შეინახავთ.
3. თუ აღდგენის გასაღებს აირჩევთ, ამოიწერეთ ის და შეინახეთ უსაფრთხო ადგილას, Mac-ისგან განცალკევებით. თუ პაროლსაც დაკარგავთ და გასაღებსაც, ფაილებს სამუდამოდ დაკარგავთ.

> [!warning]
> თუ კომპიუტერი სხვა ადამიანმა გაგიმართათ, BitLocker-ის გასაღები შესაძლოა მის Microsoft-ის ანგარიშში ინახებოდეს. მოიძიეთ ის წინასწარ, სანამ დაგჭირდებათ.

## გადაამოწმეთ, რომ ჩაშენებული დაცვა ჩართულია {#built-in-protection .recommended}

Windows-სა და macOS-ს ცნობილი მავნე პროგრამებისგან დაცვის ჩაშენებული სისტემები აქვს. მომხმარებელთა უმეტესობისთვის ეს სრულიად საკმარისია და ცალკე ანტივირუსის შეძენა საჭირო არ არის. თუ Windows-ზე სხვა ანტივირუსს დააინსტალირებთ, Microsoft Defender ავტომატურად გამოირთვება და დაცვას ახალი პროგრამა გადაიბარებს.

### Windows

1. Start მენიუში მოძებნეთ **Windows Security** და გახსენით.
2. გადაამოწმეთ, რომ განყოფილებებში **Virus & threat protection**, **Firewall & network protection** და **App & browser control** გამაფრთხილებელი ნიშნები არ ჩანდეს.
3. თუ **App & browser control**-ში **Smart App Control** ჩართულია, დატოვეთ ჩართული — ის ბლოკავს საეჭვო აპლიკაციებს. თუ მისი ჩართვა არ ხერხდება, საგანგაშო არაფერია.

### Mac

1. macOS-ში მავნე პროგრამებისგან დაცვის სისტემა XProtect ჩაშენებულია. ის ავტომატურად ახლდება და ხელით გამართვას არ საჭიროებს.
2. დატოვეთ ჩართული **Install Security Responses and system files** (იხილეთ პირველი ნაბიჯი), რათა დაცვის მექანიზმები მუდმივად განახლდეს.

## პროგრამები მხოლოდ სანდო წყაროებიდან დააინსტალირეთ {#software-sources .recommended}

უცნობი ვებსაიტიდან ან შეტყობინებაში გამოგზავნილი ბმულიდან ჩამოტვირთული პროგრამა შესაძლოა მავნე კოდს შეიცავდეს, მისი ნამდვილი ავტორის გადამოწმება კი შეუძლებელია. პროგრამები მხოლოდ ოფიციალური მაღაზიიდან ან უშუალოდ შემქმნელის ვებსაიტიდან ჩამოტვირთეთ. გაითვალისწინეთ, რომ ფასიანი პროგრამების „უფასო“ (გატეხილი) ვერსიები სწორედ ასეთი საეჭვო წყაროებიდან ვრცელდება.

### Windows

1. აპლიკაციები დააინსტალირეთ **Microsoft Store**-იდან ან დეველოპერის ოფიციალური ვებსაიტიდან.
2. მენიუში **Windows Security → App & browser control** დატოვეთ ჩართული **Reputation-based protection** — ის გაგაფრთხილებთ უცნობი ფაილების ჩამოტვირთვისას.

### Mac

1. გახსენით **Apple menu → System Settings → Privacy & Security** და ჩამოყევით **Security** განყოფილებამდე.
2. პარამეტრში **Allow applications from** აირჩიეთ **App Store** ან **App Store & Known Developers**.
3. თუ macOS რომელიმე აპლიკაციას დაბლოკავს, ნუ გახსნით მას **Open Anyway** ღილაკით, თუ ბოლომდე დარწმუნებული არ ხართ მის წარმომავლობაში.

## ყოველდღიური მუშაობისთვის გამოიყენეთ სტანდარტული ანგარიში {#standard-account .advanced}

ადმინისტრატორის ანგარიშს მთელი სისტემის შეცვლა შეუძლია — და იმავე უფლებებს იღებს ნებისმიერი მავნე პროგრამა, რომელსაც ამ ანგარიშში მუშაობისას გაუშვებთ. Microsoft გირჩევთ, ყოველდღიური საქმიანობისთვის სტანდარტული (Standard) ანგარიში გამოიყენოთ. სანაცვლოდ, განახლებების დაყენებისას, დაშიფვრის ჩართვისა და ზოგიერთი სისტემური პარამეტრის შეცვლისას ადმინისტრატორის პაროლის შეყვანა დაგჭირდებათ.

### Windows

1. მენიუში **Settings → Accounts → Other users** შექმენით მეორე ანგარიში ყოველდღიური მოხმარებისთვის.
2. დატოვეთ ერთი ადმინისტრატორის ანგარიში, დანარჩენებს კი **Change account type**-ით სტანდარტული ანგარიშის სტატუსი მიანიჭეთ.

### Mac

1. Mac-ზე შექმნილი პირველი ანგარიში ავტომატურად ადმინისტრატორია. ყოველდღიური მუშაობისთვის სტანდარტული ანგარიშის დასამატებლად გახსენით **Apple menu → System Settings → Users & Groups**.
2. ადმინისტრატორის მომხმარებლის სახელსა და პაროლს ნურავის გაუზიარებთ.

## Firewall-ი ჩართული დატოვეთ {#firewall .advanced}

Firewall-ი ბლოკავს გარე ქსელიდან თქვენს კომპიუტერში შემომავალ არასასურველ კავშირებს, რაც განსაკუთრებით მნიშვნელოვანია საჯარო Wi-Fi-ით სარგებლობისას. თუ Firewall-ი თქვენთვის საჭირო აპლიკაციას ზღუდავს, მთლიანად ნუ გამორთავთ მას — წვდომის ნებართვა მხოლოდ ამ კონკრეტულ აპლიკაციას მიეცით.

### Windows

1. **Windows Security**-ში აირჩიეთ **Firewall & network protection**.
2. გადაამოწმეთ, რომ **Microsoft Defender Firewall** ჩართული იყოს (**On**) როგორც **Private network**-ისთვის, ისე **Public network**-ისთვის.
3. კაფეს ან სასტუმროს Wi-Fi-სთან დაკავშირებისას აირჩიეთ **Public network** — ეს უფრო მკაცრი დაცვის რეჟიმია.

### Mac

1. გახსენით **Apple menu → System Settings → Network → Firewall**.
2. ჩართეთ **Firewall**. გაითვალისწინეთ, რომ ფაილებისა თუ ეკრანის გაზიარების ფუნქციებმა, რომლებსაც თავად ჩართავთ, შესაძლოა კავშირები მის გავლით მაინც გახსნას.

## გაყიდვამდე ან გასხვისებამდე სრულად გაასუფთავეთ კომპიუტერი {#before-selling .advanced}

კომპიუტერში, რომელსაც სხვას გადასცემთ, თქვენი ფაილები და აქტიური ანგარიშები მანამ რჩება, სანამ სისტემას სრულად არ წაშლით. დაწყებამდე შექმენით სარეზერვო ასლი. Windows-ის შემთხვევაში ხელთ გქონდეთ BitLocker-ის აღდგენის გასაღები.

### Windows

1. შექმენით თქვენი ფაილების სარეზერვო ასლი.
2. გახსენით **Start → Settings → System → Recovery → Reset PC**, აირჩიეთ **Remove everything** და ჩართეთ **Clean data**.
3. წაშლის პროცესში ეკრანი შესაძლოა დიდხანს შავი დარჩეს — ნუ გადატვირთავთ კომპიუტერს, სანამ პროცესი არ დასრულდება. Microsoft აღნიშნავს, რომ ეს ფუნქცია არ აკმაყოფილებს მონაცემთა განადგურების სამთავრობო სტანდარტებს.

### Mac

1. შექმენით სარეზერვო ასლი Time Machine-ით ან გადააკოპირეთ თქვენი ფაილები სხვა საცავზე.
2. Apple silicon-ის ან T2 ჩიპის მქონე Mac-ზე აირჩიეთ **Apple menu → System Settings → General → Transfer or Reset → Erase All Content and Settings** — ეს ფუნქცია გამოგიყვანთ Apple-ის სერვისებიდან და სრულად წაშლის მონაცემებს.
3. თუ თქვენს Mac-ს აქვს Apple silicon და macOS 26 (ან უფრო ახალი ვერსია) და ის ოდესმე შეუკეთებიათ (ან ამაში დარწმუნებული არ ხართ), წაშლამდე გაუშვით **Repair Assistant**. უფრო ძველ Mac-ებზე მიჰყევით Apple-ის სტანდარტულ ინსტრუქციას: გამოდით iCloud-იდან და ხელახლა დააყენეთ macOS.
