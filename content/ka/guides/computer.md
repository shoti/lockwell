კომპიუტერში ინახება თქვენი დოკუმენტები, ფოტოები და ბრაუზერი, რომლითაც ანგარიშებში შედიხართ. ეს გზამკვლევი Windows 11-სა და macOS-ის ახალ ვერსიებს ეხება. ორ **აუცილებელ** ნაბიჯს დაახლოებით ათი წუთი სჭირდება. მესამე ნაბიჯი, დაშიფვრა, ფაილებს მაშინ დაიცავს, თუ კომპიუტერს მოგპარავენ. ოღონდ ყურადღებით წაიკითხეთ: თუ აღდგენის გასაღებს დაკარგავთ, შეიძლება ფაილებიც დაკარგოთ.

## ჩართეთ ავტომატური განახლებები {#updates .essential}

განახლებები ასწორებს უსაფრთხოების იმ ხარვეზებს, რომლებიც თავდამსხმელებმა უკვე იციან. Windows-სა და macOS-ს მათი დაყენება თავად შეუძლია: შეამოწმეთ, რომ მართლა ასე ხდებოდეს, და როცა მოგთხოვთ, კომპიუტერი გადატვირთეთ. სისტემა, რომელიც უსაფრთხოების განახლებებს აღარ იღებს, დაუცველია ისეთი თავდასხმებისგან, რომელთა გამოყენებაც ნებისმიერს შეუძლია.

### Windows

1. აირჩიეთ **Start → Settings → Windows Update**. თუ განახლებები გელოდებათ, აირჩიეთ **Download & install** და, როცა მოგთხოვთ, კომპიუტერი გადატვირთეთ.
2. Windows განახლებებს თავად აყენებს. მათი შეჩერება ერთ ჯერზე 35 დღემდე შეგიძლიათ, შემდეგ კი ვადის გაგრძელებაც. უსაფრთხოების განახლებებს უმიზეზოდ ნუ შეაჩერებთ, ხოლო თუ შეაჩერეთ, რაც შეიძლება მალე ისევ ჩართეთ.
3. **Windows 10**-მა უსაფრთხოების განახლებების მიღება 2025 წლის 14 ოქტომბერს შეწყვიტა. თუ თქვენს კომპიუტერზე Windows 11 ყენდება, გადადით მასზე. თუ არა, ჩაერთეთ Extended Security Updates პროგრამაში აქედან: **Settings → Update & Security → Windows Update → Enroll now**. ასე უსაფრთხოების განახლებებს 2027 წლის 12 ოქტომბრამდე მიიღებთ. ამისთვის საჭიროა Windows 10-ის 22H2 ვერსია და Microsoft-ის ანგარიში.
4. თუ კომპიუტერზე Windows 11 არ ყენდება, კიდევ ერთი გზაა Linux, უფასო ოპერაციული სისტემა. ვინც Linux-ს პირველად იყენებს, მას Privacy Guides Fedora-ს ურჩევს. Fedora-ს თითოეული ვერსია განახლებებს დაახლოებით ერთი წელი იღებს, ამიტომ, როცა ახალ ვერსიას შემოგთავაზებთ, გადადით მასზე. Privacy Guides-ის თქმით, Linux-ით თავს აარიდებთ მონაცემების შეგროვებას, რომელიც Windows-სა და macOS-ს ხშირად ახლავს, მაგრამ Linux-ს აკლია მათი უსაფრთხოების ზოგი ფუნქცია, მაგალითად, აპლიკაციების მკაცრი იზოლაცია (sandboxing). დაყენებამდე ფაილების სარეზერვო ასლი შექმენით: ნახეთ [შექმენით კომპიუტერის სარეზერვო ასლი](/guides/backups/#computer-backup).

### Mac

1. აირჩიეთ **Apple menu → System Settings → General → Software Update**.
2. **Automatic Updates**-ის გვერდით დააჭირეთ ინფორმაციის ღილაკს და ჩართეთ **Download new updates when available**, **Install macOS updates** და **Install Security Responses and system files**.
3. Apple გვირჩევს macOS-ის უახლეს ვერსიას, რომელიც თქვენს Mac-ზე ყენდება. თუ **Software Update** უფრო ახალ ვერსიას არ გთავაზობთ, შესაძლოა, თქვენს Mac-ზე ის აღარ ყენდება.

> [!warning]
> თუ კომპიუტერი უსაფრთხოების განახლებებს აღარ იღებს, ეცადეთ, ელფოსტისთვის, ინტერნეტბანკისთვის და სხვა მნიშვნელოვანი ანგარიშებისთვის არ გამოიყენოთ. დაგეგმეთ მისი შეცვლა.

## ჩაკეტეთ ეკრანი, როცა კომპიუტერს ტოვებთ {#screen-lock .essential}

ვინც განბლოკილ კომპიუტერთან დაჯდება, თქვენი ელფოსტა, ფაილები და შენახული პაროლები ხელში ჩაუვარდება. ისე დააყენეთ, რომ კომპიუტერი თავად ჩაიკეტოს, როგორც კი ცოტა ხანს არ გამოიყენებთ. როცა კომპიუტერს ტოვებთ, თავადაც ჩაკეტეთ.

### Windows

1. აირჩიეთ **Start → Settings → Accounts → Sign-in options** და დააყენეთ **Windows Hello**: PIN კოდი, თითის ანაბეჭდი ან სახით შესვლა.
2. აირჩიეთ **Settings → System → Power & battery → Screen, sleep & hibernate timeouts** და **Turn my screen off after**-სა და **Make my device sleep after**-ში რამდენიმე წუთი მიუთითეთ.
3. **Sign-in options**-ში შეამოწმეთ, რომ ძილის რეჟიმიდან გამოსვლისას Windows ხელახლა შესვლას ითხოვდეს.
4. ეკრანის თავად ჩასაკეტად ერთდროულად დააჭირეთ Windows-ის კლავიშსა და **L**-ს.

### Mac

1. აირჩიეთ **Apple menu → System Settings → Lock Screen**.
2. **Require password after screen saver begins or display is turned off**-ში აირჩიეთ მოკლე დრო.
3. ისე დააყენეთ, რომ ეკრანი გამოირთოს, თუ Mac-ს რამდენიმე წუთი არ გამოიყენებთ, ბატარეაზე მუშაობისასაც და დენში ჩართულზეც.
4. **Users & Groups**-ში ავტომატურ შესვლას ნუ გამოიყენებთ: ასე ნებისმიერი შეძლებს, Mac გადატვირთოს და შევიდეს.

## დაშიფრეთ დისკი და შეინახეთ აღდგენის გასაღები {#disk-encryption .recommended}

დაშიფრულ დისკზე თქვენს ფაილებს ვერ წაიკითხავს ის, ვინც კომპიუტერს მოიპარავს ან დისკს ამოიღებს. აღდგენის გასაღები მაშინ დაგჭირდებათ, როცა Windows ან macOS მოგთხოვთ, მაგალითად, კომპიუტერის რომელიმე ნაწილის შეცვლის შემდეგ, ან როცა პაროლი დაგავიწყდებათ. დაკარგულ გასაღებს ვერც Microsoft აღგიდგენთ და ვერც Apple. სანამ დაშიფვრას ჩართავთ, გადაწყვიტეთ, სად შეინახავთ გასაღებს, და მისი ერთი ასლი კომპიუტერისგან მოშორებით იქონიეთ.

### Windows

1. შედით ადმინისტრატორის ანგარიშით და გახსენით **Settings → Privacy & security → Device encryption**. თუ ეს პარამეტრი ჩანს, ჩართეთ (**On**). თუ არ ჩანს და Windows Pro გაქვთ, გამოიყენეთ **BitLocker**: Start-ში ჩაწერეთ BitLocker და აირჩიეთ **Manage BitLocker → Turn on BitLocker**.
2. თუ Microsoft-ის ანგარიშით შედიხართ, შესაძლოა, Windows-მა დაშიფვრა უკვე ჩართო და გასაღები ამ ანგარიშში შეინახა. შეამოწმეთ [aka.ms/myrecoverykey](https://aka.ms/myrecoverykey)-ზე.
3. კიდევ ერთი ასლისთვის Start-ში ჩაწერეთ BitLocker, აირჩიეთ **Manage BitLocker → Back up your recovery key** და გასაღები ამობეჭდეთ ან USB ფლეშკაზე შეინახეთ. ეს ასლი კომპიუტერისგან ცალკე გქონდეთ.

### Mac

1. აირჩიეთ **Apple menu → System Settings → Privacy & Security → FileVault** და ჩართეთ FileVault.
2. აირჩიეთ, როგორ განბლოკავთ დისკს, თუ პაროლი დაგავიწყდებათ: iCloud-ის ანგარიშით თუ აღდგენის გასაღებით, რომელსაც თავად შეინახავთ.
3. თუ აღდგენის გასაღებს აირჩევთ, ჩაიწერეთ და უსაფრთხო ადგილას შეინახეთ, Mac-ისგან ცალკე. თუ პაროლსაც დაკარგავთ და გასაღებსაც, ფაილებს სამუდამოდ დაკარგავთ.

> [!warning]
> თუ კომპიუტერი სხვამ გაგიმართათ, BitLocker-ის გასაღები შეიძლება მის Microsoft-ის ანგარიშში იყოს. მოძებნეთ, სანამ დაგჭირდებათ.

## შეამოწმეთ, რომ ჩაშენებული დაცვა ჩართულია {#built-in-protection .recommended}

Windows-სა და macOS-ს ცნობილი მავნე პროგრამებისგან დაცვა თავიდანვე აქვს. ადამიანების უმეტესობისთვის ეს საკმარისია: ანტივირუსის ყიდვა საჭირო არ არის. თუ Windows-ზე სხვა ანტივირუსს დააყენებთ, Microsoft Defender თავად გამოირთვება და მის საქმეს ახალი პროგრამა გააკეთებს.

### Windows

1. Start მენიუში მოძებნეთ **Windows Security** და გახსენით.
2. შეამოწმეთ, რომ **Virus & threat protection**, **Firewall & network protection** და **App & browser control** გაფრთხილებას არ აჩვენებდეს.
3. თუ **App & browser control**-ში **Smart App Control** ჩართულია, ჩართული დატოვეთ. ის ბლოკავს აპლიკაციებს, რომელთა სანდოობაშიც ვერ რწმუნდება. თუ ვერ რთავთ, არა უშავს.

### Mac

1. macOS-ს მავნე პროგრამებისგან ჩაშენებული დაცვა აქვს, რომელსაც XProtect ჰქვია. ის თავად ახლდება და არაფრის გამართვა არ სჭირდება.
2. **Install Security Responses and system files** ჩართული დატოვეთ (ნახეთ პირველი ნაბიჯი), რომ დაცვა განახლებული იყოს.

## პროგრამები მხოლოდ სანდო ადგილებიდან დააყენეთ {#software-sources .recommended}

პროგრამაში, რომელსაც უცნობი საიტიდან ან შეტყობინებით მოსული ბმულიდან ჩამოტვირთავთ, შეიძლება მავნე კოდი იყოს, თქვენ კი ვერ შეამოწმებთ, ვინ შექმნა. პროგრამები აპლიკაციების მაღაზიიდან ან მწარმოებლის საკუთარი საიტიდან ჩამოტვირთეთ. ფასიანი პროგრამების უფასო ასლები სწორედ ასეთი უცნობი წყაროებიდან მოდის.

### Windows

1. აპლიკაციები **Microsoft Store**-იდან ან დეველოპერის საკუთარი საიტიდან დააყენეთ.
2. **Windows Security → App & browser control**-ში **Reputation-based protection** ჩართული დატოვეთ. ის გაგაფრთხილებთ, როცა უცნობ ფაილს ჩამოტვირთავთ.

### Mac

1. აირჩიეთ **Apple menu → System Settings → Privacy & Security** და ჩადით **Security**-მდე.
2. **Allow applications from**-ში აირჩიეთ **App Store** ან **App Store & Known Developers**.
3. თუ macOS აპლიკაციას ბლოკავს, **Open Anyway**-ით მხოლოდ მაშინ გახსენით, თუ ზუსტად იცით, საიდან არის ეს აპლიკაცია.

## ყოველდღიური სამუშაოსთვის გამოიყენეთ ჩვეულებრივი ანგარიში {#standard-account .advanced}

ადმინისტრატორის ანგარიშს მთელი სისტემის შეცვლა შეუძლია, ისევე როგორც ნებისმიერ მავნე პროგრამას, რომელსაც ამ ანგარიშიდან გახსნით. Microsoft გვირჩევს, ყოველდღიურად ჩვეულებრივი (standard) ანგარიში გამოიყენოთ. ოღონდ გაითვალისწინეთ: განახლებების დაყენებისას, დაშიფვრის ჩართვისას და ზოგი პარამეტრის შეცვლისას ადმინისტრატორის პაროლი დაგჭირდებათ.

### Windows

1. **Settings → Accounts → Other users**-ში შექმენით მეორე ანგარიში ყოველდღიური სამუშაოსთვის.
2. დატოვეთ ადმინისტრატორის ერთი ანგარიში, დანარჩენები კი **Change account type**-ით ჩვეულებრივ ანგარიშებად აქციეთ.

### Mac

1. Mac-ზე პირველი ანგარიში ადმინისტრატორისაა. ყოველდღიური სამუშაოსთვის ჩვეულებრივი ანგარიშის დასამატებლად აირჩიეთ **Apple menu → System Settings → Users & Groups**.
2. ადმინისტრატორის სახელსა და პაროლს ნურავის ეტყვით.

## Firewall ჩართული დატოვეთ {#firewall .advanced}

Firewall ბლოკავს არასასურველ კავშირებს, რომლებიც ქსელიდან თქვენს კომპიუტერთან მოდის. ეს ყველაზე მეტად საჯარო Wi-Fi-ზე გამოგადგებათ. თუ firewall საჭირო აპლიკაციას ბლოკავს, ნუ გამორთავთ: ნებართვა მხოლოდ ამ აპლიკაციას მიეცით.

### Windows

1. **Windows Security**-ში აირჩიეთ **Firewall & network protection**.
2. შეამოწმეთ, რომ **Microsoft Defender Firewall** ჩართული იყოს (**On**) **Private network**-ისთვისაც და **Public network**-ისთვისაც.
3. კაფეს ან სასტუმროს Wi-Fi-ზე მიერთებისას აირჩიეთ **Public network**: ეს უფრო მკაცრი პარამეტრია.

### Mac

1. აირჩიეთ **Apple menu → System Settings → Network → Firewall**.
2. ჩართეთ **Firewall**. გაზიარების ფუნქციები, რომლებსაც თავად ჩართავთ, შეიძლება მის გავლით მაინც ხსნიდეს კავშირებს.

## წაშალეთ ყველაფერი კომპიუტერიდან, სანამ გაყიდით ან სხვას მისცემთ {#before-selling .advanced}

კომპიუტერში, რომელსაც სხვას გადასცემთ, თქვენი ფაილები და ანგარიშები რჩება, სანამ ყველაფერს არ წაშლით. ჯერ სარეზერვო ასლი შექმენით. Windows-ზე BitLocker-ის აღდგენის გასაღები ხელთ გქონდეთ.

### Windows

1. შექმენით ფაილების სარეზერვო ასლი.
2. აირჩიეთ **Start → Settings → System → Recovery → Reset PC**, შემდეგ **Remove everything** და ჩართეთ **Clean data**.
3. ეკრანი შეიძლება კარგა ხანს შავი დარჩეს. სანამ წაშლა მიმდინარეობს, კომპიუტერს ნუ გადატვირთავთ. Microsoft აღნიშნავს, რომ ეს წაშლა მონაცემთა წაშლის სახელმწიფო სტანდარტებს არ აკმაყოფილებს.

### Mac

1. შექმენით სარეზერვო ასლი Time Machine-ით ან ფაილები სხვაგან გადააკოპირეთ.
2. Apple silicon-იან ან T2 ჩიპიან Mac-ზე აირჩიეთ **Apple menu → System Settings → General → Transfer or Reset → Erase All Content and Settings**. ამით Apple-ის სერვისებიდან გამოხვალთ და ყველაფერი წაიშლება.
3. თუ Mac-ს Apple silicon და macOS 26 ან უფრო ახალი ვერსია აქვს და ის ოდესმე შეუკეთებიათ, ან ეს ზუსტად არ იცით, ჯერ გაუშვით **Repair Assistant**. ძველ Mac-ებზე მიჰყევით Apple-ის ინსტრუქციას: გამოდით iCloud-იდან და ხელახლა დააყენეთ macOS.
