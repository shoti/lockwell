ტელეფონში ინახება თქვენი მიმოწერა, ფოტოები, პაროლები და ანგარიშებში შესასვლელი კოდები. ამ მონაცემების დიდ ნაწილს ეკრანის საიმედო დაბლოკვა და დროული განახლებები იცავს. სამ **აუცილებელ** ნაბიჯს დაახლოებით ოცი წუთი დასჭირდება. Android-ის მენიუები მწარმოებლისა და სისტემის ვერსიის მიხედვით განსხვავდება: თუ რომელიმე პარამეტრს ვერ პოულობთ, მისი სახელი **Settings**-ის ზედა საძიებო ველში ჩაწერეთ.

## დააყენეთ ეკრანის ძლიერი დაბლოკვა {#screen-lock .essential}

ეკრანის დაბლოკვა არ აძლევს საშუალებას უცხო პირს, თქვენი ტელეფონი აიღოს და გახსნას. მასზეა დამოკიდებული მონაცემების დაშიფვრაც: iPhone-ზე დაშიფვრა სწორედ კოდის დაყენებისას ირთვება. მოკლე ან მარტივ კოდს ადვილად გამოიცნობენ ან აკრეფისას თვალს მოჰკრავენ. გამოიყენეთ სულ მცირე ექვსნიშნა კოდი; კიდევ უფრო საიმედოა გრძელი კოდი ან პაროლი, რომელიც ასოებსაც შეიცავს. მოერიდეთ ისეთ მარტივ კომბინაციებს, როგორიცაა 0000 ან 1234.

თითის ანაბეჭდით ან სახის ამოცნობით განბლოკვა უმეტესობისთვის სავსებით მისაღებია, თუ მის უკან ძლიერი კოდი დგას. გადატვირთვის შემდეგ ტელეფონი ნებისმიერ შემთხვევაში კოდს მოგთხოვთ. თუმცა, თუ არსებობს რისკი, რომ ვინმემ ტელეფონის სახით ან თითით განბლოკვა გაიძულოთ (მაგალითად, აქციაზე ან საზღვრის კვეთისას), ბიომეტრიული განბლოკვა წინასწარ გათიშეთ ან ტელეფონი საერთოდ გამორთეთ.

### iPhone {.ios}

1. გადადით **Settings → Face ID & Passcode**-ში (Touch ID-ის მქონე iPhone-ზე — **Touch ID & Passcode**-ში).
2. დააჭირეთ **Turn Passcode On**-ს, ან **Change Passcode**-ს, თუ კოდი უკვე დაყენებული გაქვთ.
3. დააჭირეთ **Passcode Options**-ს და აირჩიეთ **Custom Numeric Code** ან **Custom Alphanumeric Code**. Apple ამ ორ ვარიანტს ყველაზე უსაფრთხოდ მიიჩნევს.
4. **Settings → Display & Brightness → Auto-Lock**-ში აირჩიეთ დაბლოკვის მოკლე დრო.

### Android {.android}

1. Pixel-ზე გახსენით **Settings → Security & privacy → Device unlock → Screen lock**. Samsung-ზე გადადით **Settings → Lock screen → Screen lock type**-ში. სხვა ტელეფონებზე პარამეტრების ძებნაში ჩაწერეთ **Screen lock**.
2. აირჩიეთ **PIN** (ექვსი ან მეტი ციფრით) ან **Password**.
3. ნუ აირჩევთ **Swipe**-ს ან **None**-ს — ისინი მოწყობილობას საერთოდ არ იცავს.

> [!note]
> ეკრანის დაბლოკვა ვერ დაგიცავთ იმ ადამიანისგან, ვინც თქვენი კოდი იცის. თუ ეჭვობთ, რომ კოდი რომელიმე ახლობელმა იცის, შეცვალეთ იგი.

## ჩართეთ ავტომატური განახლებები {#updates .essential}

პროგრამული განახლებები ასწორებს უსაფრთხოების იმ ხარვეზებს, რომელთა შესახებაც თავდამსხმელებმა უკვე იციან. ჩართეთ ავტომატური განახლება, ხოლო როდესაც ტელეფონი ახალ ვერსიას შემოგთავაზებთ, დროულად დააყენეთ. მოწყობილობა, რომელიც უსაფრთხოების განახლებებს აღარ იღებს, ყოველთვიურად უფრო დაუცველი ხდება. Google-ი Pixel 8-სა და უფრო ახალ მოდელებს განახლებებს შვიდი წლის განმავლობაში აწვდის, Samsung-ი კი შერჩეულ მოდელებს — შვიდ წლამდე. სხვა მწარმოებლებს შესაძლოა უფრო მოკლე ვადა ჰქონდეთ, ამიტომ ინფორმაცია მწარმოებლის საიტზე გადაამოწმეთ. როდესაც ტელეფონი განახლებების მიღებას შეწყვეტს, მის გამოცვლაზე იზრუნეთ.

### iPhone {.ios}

1. გადადით **Settings → General → Software Update → Automatic Updates**-ში და **iOS Updates**-ის ქვეშ ჩართეთ **Automatically Install**.
2. თუ **Settings → Privacy & Security**-ში ჩანს **Background Security Improvements**, გახსენით და იქაც ჩართეთ **Automatically Install**.
3. **Settings → Apps → App Store**-ში დარწმუნდით, რომ **App Updates** ჩართულია.

### Android {.android}

1. გახსენით **Settings → System → Software updates** და დააყენეთ ყველა ხელმისაწვდომი განახლება (Samsung-ზე — **Settings → Software update**).
2. Samsung-ზე იმავე ეკრანზე ჩართეთ **Auto download over Wi-Fi**. ძველ ვერსიებზე დააჭირეთ სამ წერტილს, შემდეგ კი აირჩიეთ **Auto download → Using Wi-Fi only**.
3. **Google Play**-ში დააჭირეთ პროფილის სურათს, გახსენით **Settings → Network Preferences → Auto-update apps** და აირჩიეთ ნებისმიერი პარამეტრი, გარდა **Don't auto-update apps**-ისა.
4. სისტემის განახლების სტატუსის შესამოწმებლად გახსენით **Settings → About phone → Android version** და ნახეთ **Android security update**-ის თარიღი (Samsung-ზე იგი **Settings → About phone → Software information**-შია). თუ თარიღი რამდენიმე თვის წინანდელია და ახალი განახლება არ იძებნება, შესაძლოა თქვენს მოდელს მხარდაჭერა შეუწყდა.

> [!tip]
> Pixel-ზე ჩამოტვირთული განახლება მხოლოდ გადატვირთვის შემდეგ ამოქმედდება. როდესაც ტელეფონი გადატვირთვას გთხოვთ, ნუ გადადებთ.

## ჩართეთ Find My ან Find Hub {#find-phone .essential}

ტელეფონის დაკარგვის ან მოპარვის შემთხვევაში, ეს სერვისები რუკაზე გაჩვენებთ მის ადგილმდებარეობას და საშუალებას გაძლევთ, სხვა მოწყობილობიდან დაბლოკოთ ან გაასუფთაოთ იგი. გაითვალისწინეთ, რომ ეს ფუნქცია მხოლოდ მაშინ დაგეხმარებათ, თუ ტელეფონის დაკარგვამდე გქონდათ გააქტიურებული. iPhone-ზე **Find My** დამატებით რთავს **Activation Lock**-საც: თქვენი Apple Account-ის პაროლის გარეშე ტელეფონს ვერავინ გაასუფთავებს და ვერ გამოიყენებს.

### iPhone {.ios}

1. გახსენით **Settings**, დააჭირეთ თქვენს სახელს, გადადით **Find My → Find My iPhone**-ში და ჩართეთ **Find My iPhone**.
2. იქვე ჩართეთ **Find My network** და **Send Last Location**, რათა ტელეფონის პოვნა მაშინაც შეძლოთ, როცა ის ინტერნეტთან არ არის დაკავშირებული ან ბატარეა თითქმის დამჯდარია.
3. თუ ტელეფონი დაიკარგა, ნებისმიერი მოწყობილობიდან გახსენით [icloud.com/find](https://www.icloud.com/find), შედით **Find Devices** ღილაკით და აირჩიეთ **Mark as Lost** (ამ გვერდზე შესასვლელად ვერიფიკაციის კოდი არ დაგჭირდებათ).

### Android {.android}

1. გახსენით **Settings → Security → Find Hub** და დარწმუნდით, რომ **Allow device to be located** ჩართულია (თუ მენიუში ვერ პოულობთ, პარამეტრების ძებნაში ჩაწერეთ **Find Hub**). Samsung-ზე დამატებით შეამოწმეთ **Settings → Security and privacy → Lost device protection**.
2. თუ ტელეფონი დაიკარგა, სხვა მოწყობილობიდან გახსენით [android.com/find](https://www.android.com/find) და შედით თქვენი Google-ის ანგარიშით.
3. შესვლისას Google-მა შესაძლოა დადასტურების კოდი სწორედ დაკარგულ ტელეფონზე გამოგიგზავნოთ. ამიტომ Google-ის სარეზერვო კოდები წინასწარ შეინახეთ უსაფრთხო ადგილას: იხილეთ [იზრუნეთ, რომ ანგარიშში დაბრუნება შეძლოთ](/guides/accounts/#recovery).

> [!warning]
> თუ ტელეფონი მოგპარეს, რუკაზე ნაჩვენებ მისამართზე თავად ნუ მიხვალთ — მიმართეთ პოლიციას. ასევე გახსოვდეთ: Apple არასდროს გიკავშირდებათ იმის სათქმელად, რომ თქვენი iPhone იპოვეს. მსგავსი შეტყობინება თაღლითობაა და თქვენი პაროლის გამოტყუებას ისახავს მიზნად.

## დამალეთ შეტყობინებების შინაარსი ჩაკეტილ ეკრანზე {#lock-screen .recommended}

ჩაკეტილ ეკრანზე გამოსულ შეტყობინებებში შესაძლოა თქვენი პირადი მიმოწერა და ანგარიშში შესასვლელი კოდები გამოჩნდეს. ამ ტექსტს ნებისმიერი დაინახავს, ვისაც თქვენი დაბლოკილი ტელეფონი ხელში მოხვდება. დააყენეთ პარამეტრები ისე, რომ შეტყობინების შინაარსი მხოლოდ ეკრანის განბლოკვის შემდეგ ჩანდეს. ზოგიერთმა აპლიკაციამ შესაძლოა მაინც იმაზე მეტი გამოაჩინოს, ვიდრე ელით, ამიტომ თავად შეამოწმეთ, რა ჩანს თქვენს ჩაკეტილ ეკრანზე.

### iPhone {.ios}

1. გადადით **Settings → Notifications → Show Previews**-ში და აირჩიეთ **When Unlocked**. შეტყობინების ტექსტი მაშინვე გამოჩნდება, როგორც კი Face ID ან Touch ID გიცნობთ.
2. **Settings → Face ID & Passcode**-ში ჩამოდით განყოფილებამდე **Allow Access When Locked** და გათიშეთ ყველა ის ფუნქცია, რომელიც ეკრანის განბლოკვამდე არ გჭირდებათ.

### Android {.android}

1. Pixel-ზე გახსენით **Settings → Notifications → Notifications on lock screen** და გამორთეთ **Show sensitive content** (ძველ მოდელებზე მას **Sensitive notifications** ჰქვია).
2. Samsung-ზე გახსენით **Settings → Notifications → Hide content while locked** და აირჩიეთ **Hide when locked** (ძველ მოდელებზე მოძებნეთ **Notifications → Advanced settings**-ში ან **Additional settings**-ში).

## შეამოწმეთ, რაზე აქვთ წვდომა აპლიკაციებს {#app-permissions .recommended}

აპლიკაციები ხშირად ითხოვენ წვდომას თქვენს ადგილმდებარეობაზე, კამერაზე, მიკროფონზე, კონტაქტებსა და ფოტოებზე, და ეს ნებართვა ძალაში რჩება, სანამ თავად არ გააუქმებთ. პირველ რიგში წაშალეთ აპლიკაციები, რომლებსაც აღარ იყენებთ, შემდეგ კი დანარჩენებს გაუუქმეთ ის წვდომა, რომელიც მუშაობისთვის არ სჭირდებათ. თუ რომელიმე ფუნქცია შეფერხდება, ნებართვის თავიდან ჩართვას ნებისმიერ დროს შეძლებთ.

### iPhone {.ios}

1. გადადით **Settings → Privacy & Security → Location Services**-ში და სათითაოდ გადახედეთ აპლიკაციებს. ადგილმდებარეობაზე წვდომა დაუშვით მხოლოდ აპლიკაციის გამოყენების დროს (**While Using the App**) ან საერთოდ გათიშეთ (**Never**). გამორთეთ **Precise Location** იქ, სადაც მიახლოებითი მდებარეობაც საკმარისია (მაგალითად, ამინდის აპლიკაციაში).
2. დაბრუნდით **Privacy & Security**-ში და იმავე პრინციპით შეამოწმეთ **Camera**, **Microphone** და სხვა კატეგორიები.
3. ეკრანის ზედა ნაწილში ანთებული მწვანე წერტილი მიანიშნებს, რომ რომელიღაც აპლიკაცია კამერას იყენებს, ნარინჯისფერი კი — მიკროფონს.

### Android {.android}

1. გახსენით **Settings → Security & privacy → Privacy → Permission manager** (ზოგიერთ ტელეფონზე: **Settings → Apps** → აირჩიეთ აპლიკაცია → **Permissions**).
2. შედით **Location**-, **Camera**- და **Microphone**-განყოფილებებში და იმ აპლიკაციებისთვის, რომლებსაც მუდმივი წვდომა არ სჭირდება, აირჩიეთ **Allow only while using the app**, **Ask every time** ან **Don't allow**.
3. გეოლოკაციის პარამეტრებში გამორთეთ **Use precise location** ყველგან, სადაც მიახლოებითი მდებარეობაც საკმარისია.
4. ეკრანის ზედა მარჯვენა კუთხეში გამოჩენილი მწვანე ინდიკატორი ნიშნავს, რომ კამერა ან მიკროფონი ჩართულია. ჩამოშალეთ ზედა პანელი და დააჭირეთ ამ ნიშანს, რათა ნახოთ, რომელი აპლიკაცია იყენებს მას.

## აპლიკაციები მხოლოდ ოფიციალური მაღაზიიდან დააინსტალირეთ {#app-sources .recommended}

მავნე პროგრამები ტელეფონში ყველაზე ხშირად საეჭვო ბმულებიდან, შეტყობინებებიდან და უცნობი საიტებიდან ჩამოტვირთული აპლიკაციებით ხვდება. თაღლითები ზოგჯერ ტელეფონით რეკავენ ან გწერენ და ბმულიდან აპლიკაციის დაყენებას გთხოვენ — ნუ დაეთანხმებით და იხილეთ [გათიშეთ ზარი, თუ ფულს ან კოდს გთხოვენ](/guides/phishing/#phone-calls). ოფიციალური მაღაზიები აპლიკაციებს გამოქვეყნებამდე ამოწმებს, რაც რისკს მნიშვნელოვნად ამცირებს (თუმცა სრულად არ გამორიცხავს). თუ აპლიკაციებს მხოლოდ ოფიციალური წყაროდან აყენებთ და სისტემას დროულად ანახლებთ, ცალკე ანტივირუსული აპლიკაცია არ გჭირდებათ.

### iPhone {.ios}

1. აპლიკაციები მხოლოდ **App Store**-იდან დააინსტალირეთ.
2. ნუ გაუკეთებთ iPhone-ს Jailbreak-ს — Apple-ის განმარტებით, ეს სისტემის ჩაშენებულ დაცვის მექანიზმებს თიშავს.

### Android {.android}

1. აპლიკაციები მხოლოდ **Google Play**-დან ან ტელეფონის მწარმოებლის ოფიციალური მაღაზიიდან (მაგალითად, **Galaxy Store**-იდან) დააინსტალირეთ.
2. **Google Play**-ში დააჭირეთ პროფილის სურათს, გადადით **Play Protect → Settings**-ში და დარწმუნდით, რომ **Scan apps with Play Protect** ჩართულია.
3. Samsung-ზე გახსენით **Settings → Security and privacy → Auto Blocker** და გაააქტიურეთ. ის არაოფიციალური წყაროებიდან აპლიკაციების დაყენებას ბლოკავს.
4. თუ რომელიმე აპლიკაცია ან ბრაუზერი უცხო წყაროდან პროგრამის ინსტალაციის ნებართვას გთხოვთ, უარი თქვით.

## დაიცავით SIM ბარათი PIN კოდით {#sim-pin .recommended}

თუ ვინმე თქვენი ტელეფონიდან SIM ბარათს ამოიღებს და სხვა ტელეფონში ჩადებს, ის თქვენი ზარებისა და SMS კოდების მიღებას შეძლებს. SIM PIN-ის ჩართვის შემდეგ ბარათი კოდს მოითხოვს ტელეფონის ყოველი გადატვირთვისას და სხვა მოწყობილობაში მოთავსებისას. თუმცა ეს ვერ შეაჩერებს თავდამსხმელს, რომელიც მობილურ ოპერატორს მოტყუებით თქვენს ნომერს ახალ SIM ბარათზე გადაატანინებს. ამ რისკისგან თავის დასაცავად, სადაც შესაძლებელია, SMS-ის ნაცვლად ვერიფიკაციის უფრო საიმედო მეთოდი აირჩიეთ (იხილეთ [ორსაფეხურიანი ვერიფიკაცია](/guides/accounts/#two-step)).

დაყენებამდე დაგჭირდებათ SIM ბარათის მიმდინარე PIN კოდი. ის მითითებულია ბარათის პლასტიკურ ჩარჩოზე ან დოკუმენტაციაში; ასევე შეგიძლიათ მობილურ ოპერატორთან გადაამოწმოთ.

### iPhone {.ios}

1. გადადით **Settings → Cellular → SIM PIN**-ში (ზოგიერთ რეგიონში მენიუს **Mobile Service** ჰქვია). თუ ორი SIM ბარათი გაქვთ, ჯერ სასურველ ნომერს დააჭირეთ.
2. ჩართეთ **SIM PIN** და შეიყვანეთ ბარათის მიმდინარე PIN კოდი.
3. თუ ბარათზე ჯერ კიდევ ოპერატორის მიერ მინიჭებული სტანდარტული კოდი აყენია, იქვე შეცვალეთ იგი კოდით, რომელიც მხოლოდ თქვენ იცით.

### Android {.android}

1. Pixel-ზე გახსენით **Settings → Security & privacy → More security settings → SIM lock** და ჩართეთ **Lock SIM**. სხვა ტელეფონებზე პარამეტრების ძებნაში ჩაწერეთ **SIM**.
2. შეიყვანეთ ბარათის მიმდინარე PIN კოდი.
3. თუ ჯერ კიდევ ოპერატორის სტანდარტული კოდია აქტიური, შეცვალეთ იგი ახალი კოდით.

> [!warning]
> ნუ ეცდებით SIM PIN-ის ვარაუდით გამოცნობას. რამდენიმე არასწორი მცდელობის შემდეგ ბარათი დაიბლოკება და PUK კოდს მოითხოვს, რომლის მიღებაც მხოლოდ ოპერატორისგან შეგიძლიათ. PUK კოდის რამდენჯერმე არასწორად შეყვანა კი SIM ბარათს სამუდამოდ გააფუჭებს.

## ჩართეთ ქურდობისგან დაცვა {#theft-protection .advanced}

ზოგჯერ მძარცველები ჯერ აკვირდებიან, რა კოდს კრეფთ ეკრანზე, და ტელეფონს მხოლოდ ამის შემდეგ იპარავენ. ქურდობისგან დაცვის ფუნქცია პაროლების შესაცვლელად ან **Find My**-ის გასათიშად სახის ამოცნობას ან თითის ანაბეჭდს ითხოვს, ხშირად კი დამატებით ერთსაათიან დაყოვნებასაც რთავს. ეს შეზღუდვა მოქმედებს მაშინ, როცა თქვენთვის ჩვეული ადგილებიდან (სახლი, სამსახური) შორს იმყოფებით, ან მუდმივად — თუ შესაბამის პარამეტრს აირჩევთ. გახსოვდეთ, ეს ფუნქცია მხოლოდ დროს გაგებინებთ: მოპარული ტელეფონი რაც შეიძლება სწრაფად მონიშნეთ დაკარგულად. გაითვალისწინეთ ისიც, რომ თუ სენსორი თქვენს სახეს ან თითის ანაბეჭდს ხშირად ვერ ცნობს, ერთსაათიანი ლოდინი თავადაც შეგაწუხებთ.

### iPhone {.ios}

1. გადადით **Settings → Face ID & Passcode**-ში და შეიყვანეთ ეკრანის კოდი.
2. დააჭირეთ **Stolen Device Protection**-ს და ჩართეთ (შესაძლოა, უკვე გააქტიურებულიც იყოს). მის სამუშაოდ საჭიროა Face ID ან Touch ID, Find My, Apple Account-ის ორსაფეხურიანი ვერიფიკაცია და ჩართული **Significant Locations** (**Location Services**-ში).
3. თუ გსურთ, რომ დაცვითი დაყოვნება ნებისმიერ ადგილას მოქმედებდეს, აირჩიეთ **Always**.

### Android {.android}

1. გახსენით **Settings → Google → All services → Theft protection** (Samsung-ზე: **Settings → Security and privacy → Lost device protection → Theft protection**).
2. ჩართეთ **Theft Detection Lock** და **Offline Device Lock** — ისინი ავტომატურად კეტავს ეკრანს, როდესაც ტელეფონს ხელიდან გტაცებენ ან ქსელიდან თიშავენ.
3. ჩართეთ **Remote Lock** და დაადასტურეთ თქვენი ნომერი. ამის შემდეგ ტელეფონის დისტანციურად დაბლოკვას გვერდზე [android.com/lock](https://www.android.com/lock) მხოლოდ ტელეფონის ნომრითაც შეძლებთ.
4. თუ სიაში ხელმისაწვდომია **Identity Check**, გაააქტიურეთ ისიც.

## გაასუფთავეთ ტელეფონი გაყიდვამდე ან გასხვისებამდე {#before-selling .advanced}

ტელეფონში, რომელსაც ყიდით ან სხვას გადასცემთ, თქვენი ანგარიშები და ფოტოები მანამ რჩება, სანამ სისტემას ქარხნულ პარამეტრებზე არ დააბრუნებთ. გასუფთავებამდე დარწმუნდით, რომ ანგარიშებზე წვდომას არ დაკარგავთ: შექმენით სარეზერვო ასლი (Backup-ი), ხოლო ავთენტიფიკატორი აპლიკაცია და ტელეფონის ნომერი ახალ მოწყობილობაზე გადაიტანეთ. iPhone-ის სრული გასუფთავება შლის დაშიფვრის გასაღებებს, რის შემდეგაც ძველი მონაცემების აღდგენა შეუძლებელია.

### iPhone {.ios}

1. შექმენით ტელეფონის სარეზერვო ასლი. გადაიტანეთ ავთენტიფიკატორი აპლიკაცია და SIM ბარათი ახალ ტელეფონზე და შეამოწმეთ, რომ ანგარიშებში უპრობლემოდ შედიხართ.
2. **Settings → Face ID & Passcode**-ში გამორთეთ **Stolen Device Protection**.
3. გახსენით **Settings**, დააჭირეთ თქვენს სახელს, ჩამოდით ბოლოში და აირჩიეთ **Sign Out**.
4. გადადით **Settings → General → Transfer or Reset iPhone → Erase All Content and Settings**-ში.

### Android {.android}

1. შექმენით ტელეფონის სარეზერვო ასლი. გადაიტანეთ ავთენტიფიკატორი აპლიკაცია და SIM ბარათი ახალ ტელეფონზე და შეამოწმეთ, რომ ანგარიშებში შედიხართ.
2. Pixel-ზე გახსენით **Settings → System → Reset options → Erase all data (factory reset)**. Samsung-ზე გადადით **Settings → General management → Reset → Factory data reset**-ში.
3. ქარხნულ პარამეტრებზე დაბრუნება აუცილებლად **Settings**-იდან შეასრულეთ — ღილაკების კომბინაციით გასუფთავების შემთხვევაში, ტელეფონი ახალ მფლობელს თქვენი Google-ის ანგარიშის მონაცემებს მოსთხოვს.

> [!tip]
> მეორადი ტელეფონის შეძენისას მოწყობილობა საწყისი მისალმების ეკრანით უნდა ჩაირთოს. თუ ის წინა მფლობელის Apple Account-ს ან Google-ის ანგარიშს ითხოვს, ტელეფონი კვლავ სხვის სახელზეა დაბლოკილი — ნუ შეიძენთ მას.
