ტელეფონში გაქვთ მიმოწერა, ფოტოები, შენახული პაროლები და კოდები, რომლებითაც ანგარიშებში შედიხართ. ამის დიდ ნაწილს ეკრანის ძლიერი დაბლოკვა და დროული განახლებები იცავს. სამ **აუცილებელ** ნაბიჯს დაახლოებით ოცი წუთი სჭირდება. Android-ის მენიუები მწარმოებლისა და ვერსიის მიხედვით განსხვავდება: თუ რომელიმე პარამეტრს ვერ პოულობთ, მისი სახელი **Settings**-ის ზედა საძიებო ველში ჩაწერეთ.

## დააყენეთ ეკრანის ძლიერი დაბლოკვა {#screen-lock .essential}

თუ ეკრანი დაბლოკილია, ვინც თქვენს ტელეფონს აიღებს, ვერ გახსნის. დაბლოკვაზეა დამოკიდებული მონაცემების დაშიფვრაც: iPhone-ზე დაშიფვრა სწორედ კოდის დაყენებისას ირთვება. მოკლე ან მარტივ კოდს ადვილად გამოიცნობენ ან დაინახავენ, როცა კრეფთ. გამოიყენეთ სულ მცირე ექვსი ციფრი. კიდევ უფრო ძლიერია გრძელი კოდი ან პაროლი, რომელშიც ასოებიც არის. ნუ გამოიყენებთ ისეთ კოდებს, როგორიცაა 0000 ან 1234.

თითის ანაბეჭდით ან სახით განბლოკვა უმეტესობისთვის მისაღებია, თუ მასთან ერთად ძლიერი კოდიც გაქვთ. გადატვირთვის შემდეგ ტელეფონი მაინც კოდს მოგთხოვთ. თუ შეიძლება ვინმემ გაიძულოთ, ტელეფონი სახით ან თითით განბლოკოთ, მაგალითად, აქციაზე ან საზღვარზე, სახითა და თითით განბლოკვა წინასწარ გამორთეთ, ან ტელეფონი საერთოდ გამორთეთ.

### iPhone {.ios}

1. გადადით **Settings → Face ID & Passcode**-ში. Touch ID-იან iPhone-ზე ეს **Touch ID & Passcode**-ია.
2. დააჭირეთ **Turn Passcode On**-ს, ან **Change Passcode**-ს, თუ კოდი უკვე გაქვთ.
3. დააჭირეთ **Passcode Options**-ს და აირჩიეთ **Custom Numeric Code** ან **Custom Alphanumeric Code**. Apple ამ ორ ვარიანტს ყველაზე უსაფრთხოს უწოდებს.
4. **Settings → Display & Brightness → Auto-Lock**-ში აირჩიეთ მოკლე დრო.

### Android {.android}

1. Pixel-ზე გახსენით **Settings → Security & privacy → Device unlock → Screen lock**. Samsung-ზე გახსენით **Settings → Lock screen → Screen lock type**. სხვა ტელეფონებზე პარამეტრებში მოძებნეთ **Screen lock**.
2. აირჩიეთ **PIN** ექვსი ან მეტი ციფრით, ან **Password**.
3. ნუ აირჩევთ **Swipe**-ს ან **None**-ს: ისინი საერთოდ არ გიცავთ.

> [!note]
> ეკრანის დაბლოკვა ვერ დაგიცავთ მისგან, ვინც თქვენი კოდი იცის. თუ კოდი შეიძლება რომელიმე ახლობელმა იცოდეს, შეცვალეთ.

## ჩართეთ ავტომატური განახლებები {#updates .essential}

განახლებები უსაფრთხოების იმ ხარვეზებს ასწორებს, რომლებიც თავდამსხმელებმა უკვე იციან. ჩართეთ ავტომატური განახლება, ხოლო როცა ტელეფონი განახლებას შემოგთავაზებთ, დააყენეთ. ტელეფონი, რომელიც უსაფრთხოების განახლებებს აღარ იღებს, ყოველთვიურად უფრო დაუცველი ხდება. Google Pixel 8-სა და უფრო ახალ მოდელებს განახლებებს შვიდი წელი ჰპირდება, Samsung კი ზოგ მოდელს შვიდ წლამდე. სხვა მწარმოებლები შეიძლება ნაკლებს გპირდებოდნენ, ამიტომ თქვენი ტელეფონის მწარმოებლის საიტზე შეამოწმეთ. როცა ტელეფონი განახლებებს აღარ მიიღებს, მის გამოცვლაზე იფიქრეთ.

### iPhone {.ios}

1. გადადით **Settings → General → Software Update → Automatic Updates**-ში და **iOS Updates**-ის ქვეშ ჩართეთ **Automatically Install**.
2. თუ **Settings → Privacy & Security**-ში ხედავთ **Background Security Improvements**-ს, გახსენით და იქაც ჩართეთ **Automatically Install**.
3. **Settings → Apps → App Store**-ში შეამოწმეთ, რომ **App Updates** ჩართული იყოს.

### Android {.android}

1. გახსენით **Settings → System → Software updates** და დააყენეთ ყველა განახლება, რომელიც იქ დაგხვდებათ. Samsung-ზე ეს **Settings → Software update**-ია.
2. Samsung-ზე იმავე ეკრანზე ჩართეთ **Auto download over Wi-Fi**. ძველ ვერსიებზე დააჭირეთ სამ წერტილს, შემდეგ **Auto download → Using Wi-Fi only**-ს.
3. Google Play-ში დააჭირეთ პროფილის სურათს, შემდეგ **Settings → Network Preferences → Auto-update apps**-ს და აირჩიეთ ნებისმიერი ვარიანტი, გარდა **Don't auto-update apps**-ისა.
4. რამდენად ახალია ტელეფონის სისტემა, ასე ნახავთ: გახსენით **Settings → About phone → Android version** და შეხედეთ **Android security update**-ის თარიღს. Samsung-ზე ის **Settings → About phone → Software information**-შია. თუ თარიღი რამდენიმე თვის წინანდელია და ახალი განახლება არ ჩანს, შესაძლოა, მწარმოებელი ტელეფონს აღარ ანახლებს.

> [!tip]
> Pixel-ზე დაყენებული განახლება მხოლოდ გადატვირთვის შემდეგ იწყებს მუშაობას. როცა ტელეფონი გთხოვთ, გადატვირთეთ.

## ჩართეთ Find My ან Find Hub {#find-phone .essential}

თუ ტელეფონი დაკარგეთ ან მოგპარეს, ეს სერვისები გაჩვენებთ, სად არის, და სხვა მოწყობილობიდან მის დაბლოკვას ან წაშლას შეძლებთ. ისინი მხოლოდ მაშინ მუშაობს, თუ ტელეფონის დაკარგვამდე გქონდათ ჩართული. iPhone-ზე Find My Activation Lock-საც რთავს: თქვენი Apple Account-ის პაროლის გარეშე ტელეფონს ვერავინ წაშლის და თავიდან ვერ გამოიყენებს.

### iPhone {.ios}

1. გახსენით **Settings**, დააჭირეთ თქვენს სახელს, შემდეგ **Find My → Find My iPhone**-ს და ჩართეთ **Find My iPhone**.
2. ჩართეთ **Find My network** და **Send Last Location**, რომ ტელეფონი მაშინაც იპოვოთ, როცა ინტერნეტი არ აქვს ან ბატარეა თითქმის დაუჯდა.
3. თუ ტელეფონი დაიკარგა, ნებისმიერი მოწყობილობიდან გახსენით [icloud.com/find](https://www.icloud.com/find), შედით **Find Devices** ღილაკით და აირჩიეთ **Mark as Lost**. იქ შესვლის კოდი არ დაგჭირდებათ.

### Android {.android}

1. გახსენით **Settings → Security → Find Hub** და შეამოწმეთ, რომ **Allow device to be located** ჩართული იყოს. თუ ვერ პოულობთ, პარამეტრებში მოძებნეთ **Find Hub**. Samsung-ზე **Settings → Security and privacy → Lost device protection**-იც შეამოწმეთ.
2. თუ ტელეფონი დაიკარგა, სხვა მოწყობილობიდან გახსენით [android.com/find](https://www.android.com/find) და შედით Google-ის ანგარიშით.
3. შესვლისას კოდი შეიძლება სწორედ იმ ტელეფონზე მოვიდეს, რომელიც დაკარგეთ. ამიტომ Google-ის სარეზერვო კოდები უსაფრთხო ადგილას შეინახეთ: ნახეთ [იზრუნეთ, რომ ანგარიშში დაბრუნება შეძლოთ](/guides/accounts/#recovery).

> [!warning]
> თუ ტელეფონი მოგპარეს, რუკაზე ნაჩვენებ ადგილას თავად ნუ წახვალთ, პოლიციას მიმართეთ. Apple არასოდეს დაგიკავშირდებათ იმის სათქმელად, რომ თქვენი iPhone იპოვეს: ასეთი შეტყობინება თაღლითობაა და პაროლის გამოტყუებას ისახავს მიზნად.

## დამალეთ შეტყობინებების შინაარსი ჩაკეტილ ეკრანზე {#lock-screen .recommended}

ჩაკეტილ ეკრანზე მოსულ შეტყობინებებში შეიძლება თქვენი მიმოწერა და შესვლის კოდები ჩანდეს. მათ ყველა დაინახავს, ვისაც ტელეფონი ხელში უჭირავს, თუნდაც ის ჩაკეტილი იყოს. ისე დააყენეთ, რომ შინაარსი მხოლოდ განბლოკვის შემდეგ გამოჩნდეს. ზოგმა აპლიკაციამ შეიძლება მაინც იმაზე მეტი აჩვენოს, ვიდრე ელით, ამიტომ შეამოწმეთ, რა ჩანს თქვენს ჩაკეტილ ეკრანზე.

### iPhone {.ios}

1. გადადით **Settings → Notifications → Show Previews**-ში და აირჩიეთ **When Unlocked**. შინაარსი მაინც გამოჩნდება, როგორც კი Face ID ან Touch ID გიცნობთ.
2. **Settings → Face ID & Passcode**-ში იპოვეთ **Allow Access When Locked** და გამორთეთ ის, რაც განბლოკვამდე არ გჭირდებათ.

### Android {.android}

1. Pixel-ზე გახსენით **Settings → Notifications → Notifications on lock screen** და გამორთეთ **Show sensitive content**. ძველ ტელეფონებზე მას **Sensitive notifications** ჰქვია.
2. Samsung-ზე გახსენით **Settings → Notifications → Hide content while locked** და აირჩიეთ **Hide when locked**. ძველ Samsung-ებზე ის **Notifications → Advanced settings**-ში ან **Additional settings**-ში მოძებნეთ.

## შეამოწმეთ, რაზე აქვთ წვდომა აპლიკაციებს {#app-permissions .recommended}

აპლიკაციები ითხოვენ წვდომას თქვენს ადგილმდებარეობაზე, კამერაზე, მიკროფონზე, კონტაქტებსა და ფოტოებზე, და ეს წვდომა მანამდე რჩებათ, სანამ თავად არ გაუუქმებთ. ჯერ წაშალეთ აპლიკაციები, რომლებსაც აღარ იყენებთ. შემდეგ გააუქმეთ ის წვდომა, რომელიც აპლიკაციას არ სჭირდება. თუ აპლიკაციამ მუშაობა შეწყვიტა, წვდომას ისევ ჩაურთავთ.

### iPhone {.ios}

1. გადადით **Settings → Privacy & Security → Location Services**-ში და აპლიკაციები სათითაოდ გახსენით. ადგილმდებარეობა მხოლოდ აპლიკაციის გამოყენების დროს დაუშვით, ან საერთოდ ნუ დაუშვებთ. გამორთეთ **Precise Location** იქ, სადაც მიახლოებითი ადგილიც საკმარისია, მაგალითად, ამინდის აპლიკაციაში.
2. დაბრუნდით **Privacy & Security**-ში და ასევე შეამოწმეთ **Camera**, **Microphone** და სხვა კატეგორიები.
3. ეკრანის ზედა ნაწილში მწვანე წერტილი ნიშნავს, რომ რომელიღაც აპლიკაცია კამერას იყენებს, ნარინჯისფერი კი მიკროფონს.

### Android {.android}

1. გახსენით **Settings → Security & privacy → Privacy → Permission manager**. ზოგ ტელეფონზე ეს **Settings → Apps**-შია: აირჩიეთ აპლიკაცია, შემდეგ **Permissions**.
2. დააჭირეთ **Location**-ს, **Camera**-ს ან **Microphone**-ს და აპლიკაციებს, რომლებსაც ეს არ სჭირდებათ, აურჩიეთ **Allow only while using the app**, **Ask every time** ან **Don't allow**.
3. ადგილმდებარეობისთვის გამორთეთ **Use precise location** იქ, სადაც მიახლოებითი ადგილიც საკმარისია.
4. ზედა მარჯვენა კუთხეში მწვანე ნიშანი ნიშნავს, რომ რომელიღაც აპლიკაცია კამერას ან მიკროფონს იყენებს. ეკრანი ზემოდან ჩამოსწიეთ და ამ ნიშანს დააჭირეთ, რომ ნახოთ, რომელი აპლიკაციაა.

## აპლიკაციები მხოლოდ ოფიციალური მაღაზიიდან დააყენეთ {#app-sources .recommended}

მავნე პროგრამა ტელეფონში ხშირად იმ აპლიკაციებით ხვდება, რომლებსაც ბმულებიდან, შეტყობინებებიდან და უცნობი საიტებიდან ჩამოტვირთავენ. თაღლითები ზოგჯერ რეკავენ ან წერენ და გთხოვენ, აპლიკაცია ბმულიდან დააყენოთ. ნუ დააყენებთ და ნახეთ [გათიშეთ ზარი, თუ ფულს ან კოდს გთხოვენ](/guides/phishing/#phone-calls). ოფიციალური მაღაზიები აპლიკაციებს ამოწმებს. ეს რისკს ამცირებს, მაგრამ ბოლომდე ვერ აქრობს. თუ აპლიკაციებს მხოლოდ ოფიციალური მაღაზიიდან აყენებთ და ტელეფონს ანახლებთ, ანტივირუსი არ გჭირდებათ.

### iPhone {.ios}

1. აპლიკაციები მხოლოდ **App Store**-იდან დააყენეთ.
2. iPhone-ს jailbreak ნუ გაუკეთებთ. Apple წერს, რომ ის ტელეფონის უსაფრთხოების ფუნქციებს გვერდს უვლის.

### Android {.android}

1. აპლიკაციები მხოლოდ **Google Play**-დან ან ტელეფონის მწარმოებლის მაღაზიიდან დააყენეთ, მაგალითად, **Galaxy Store**-იდან.
2. Google Play-ში დააჭირეთ პროფილის სურათს, შემდეგ **Play Protect → Settings**-ს და შეამოწმეთ, რომ **Scan apps with Play Protect** ჩართული იყოს.
3. Samsung-ზე გახსენით **Settings → Security and privacy → Auto Blocker** და ჩართეთ. ის სხვა წყაროებიდან აპლიკაციების დაყენებას ბლოკავს.
4. თუ ტელეფონი გკითხავთ, დაუშვათ თუ არა აპლიკაციების დაყენება სხვა წყაროდან, უარი თქვით.

## დაიცავით SIM ბარათი PIN კოდით {#sim-pin .recommended}

ვინც თქვენს SIM ბარათს ამოიღებს, შეუძლია ის სხვა ტელეფონში ჩადოს და თქვენი ზარები და SMS კოდები მიიღოს. SIM PIN-ის ჩართვის შემდეგ ბარათი კოდს ითხოვს ტელეფონის ყოველი გადატვირთვისას და მაშინაც, როცა სხვა ტელეფონში ჩადებენ. ის ვერ შეაჩერებს მას, ვინც მობილურ ოპერატორს დაარწმუნებს, რომ თქვენი ნომერი ახალ SIM ბარათზე გადაიტანოს. ამისგან რომ დაიცვათ თავი, სადაც შესაძლებელია, SMS-ის ნაცვლად შესვლის სხვა მეთოდი გამოიყენეთ (ნახეთ [ორსაფეხურიანი ვერიფიკაცია](/guides/accounts/#two-step)).

ჯერ SIM ბარათის ახლანდელი PIN უნდა იცოდეთ. ის იმ საბუთებში წერია, რომლებიც ბარათს მოჰყვა, ან მობილური ოპერატორი გეტყვით.

### iPhone {.ios}

1. გადადით **Settings → Cellular → SIM PIN**-ში. აშშ-ის გარეთ ამ პუნქტს შეიძლება **Mobile Service** ერქვას. თუ ორი SIM გაქვთ, ჯერ ნომერს დააჭირეთ.
2. ჩართეთ **SIM PIN** და აკრიფეთ ახლანდელი PIN.
3. თუ ეს ჯერ კიდევ ის PIN-ია, რომელიც ოპერატორმა მოგცათ, იმავე ეკრანზე შეცვალეთ ისეთით, რომელიც მხოლოდ თქვენ იცით.

### Android {.android}

1. Pixel-ზე გახსენით **Settings → Security & privacy → More security settings → SIM lock** და დააჭირეთ **Lock SIM**-ს. სხვა ტელეფონებზე პარამეტრებში მოძებნეთ **SIM**.
2. აკრიფეთ ახლანდელი PIN.
3. თუ ეს ჯერ კიდევ ის PIN-ია, რომელიც ოპერატორმა მოგცათ, შეცვალეთ ისეთით, რომელიც მხოლოდ თქვენ იცით.

> [!warning]
> SIM PIN-ის გამოცნობას ნუ შეეცდებით. რამდენიმე არასწორი ცდის შემდეგ ბარათი იბლოკება და PUK კოდს ითხოვს, რომელსაც მხოლოდ ოპერატორი მოგცემთ. თუ PUK კოდსაც არასწორად აკრეფთ, ბარათი შეიძლება სამუდამოდ გამოუსადეგარი გახდეს.

## ჩართეთ ქურდობისგან დაცვა {#theft-protection .advanced}

ზოგი ქურდი ჯერ უყურებს, როგორ კრეფთ კოდს, და ტელეფონს მერე იპარავს. როცა ეს ფუნქციები ჩართულია, პაროლების შესაცვლელად ან Find My-ის გამოსართავად სახე ან თითის ანაბეჭდია საჭირო, ზოგჯერ კი ერთი საათის ლოდინიც. დამატებითი შემოწმება მაშინ ირთვება, როცა იმ ადგილებიდან შორს ხართ, სადაც ხშირად ბრძანდებით, ან ყველგან, თუ ასე აირჩევთ. ეს მხოლოდ დროს გაძლევთ: ტელეფონი რაც შეიძლება მალე მონიშნეთ დაკარგულად. თუ ტელეფონი თქვენს სახეს ან თითის ანაბეჭდს ხშირად ვერ ცნობს, იცოდეთ, რომ ლოდინი ხშირად მოგიწევთ.

### iPhone {.ios}

1. გადადით **Settings → Face ID & Passcode**-ში და აკრიფეთ კოდი.
2. დააჭირეთ **Stolen Device Protection**-ს და ჩართეთ. შესაძლოა, უკვე ჩართულია. მას სჭირდება Face ID ან Touch ID, Find My, Apple Account-ის ორსაფეხურიანი ვერიფიკაცია და **Significant Locations** (Location Services-ში).
3. თუ გინდათ, რომ ლოდინი ყველგან მოქმედებდეს, აირჩიეთ **Always**.

### Android {.android}

1. გახსენით **Settings → Google → All services → Theft protection**. Samsung-ზე გახსენით **Settings → Security and privacy → Lost device protection → Theft protection**.
2. ჩართეთ **Theft Detection Lock** და **Offline Device Lock**. ისინი ეკრანს კეტავს, როცა ტელეფონს ხელიდან გტაცებენ ან ინტერნეტს უთიშავენ.
3. ჩართეთ **Remote Lock** და დაადასტურეთ ტელეფონის ნომერი. ამის შემდეგ ტელეფონის დაბლოკვას [android.com/lock](https://www.android.com/lock)-ზე თქვენი ნომრით შეძლებთ.
4. თუ სიაში **Identity Check** ჩანს, ისიც ჩართეთ.

## გაასუფთავეთ ტელეფონი, სანამ გაყიდით ან სხვას მისცემთ {#before-selling .advanced}

ტელეფონში, რომელსაც სხვას აძლევთ, თქვენი ანგარიშები და ფოტოები რჩება, სანამ არ გაასუფთავებთ. გასუფთავებამდე იზრუნეთ, რომ საკუთარ ანგარიშებში შესვლა არ გაგიჭირდეთ: შექმენით სარეზერვო ასლი და შესვლის კოდები ახალ ტელეფონზე გადაიტანეთ. iPhone-ზე გასუფთავება დაშიფვრის გასაღებებს ანადგურებს, ამიტომ ძველ მონაცემებს ვეღარავინ წაიკითხავს.

### iPhone {.ios}

1. შექმენით ტელეფონის სარეზერვო ასლი. ავთენტიფიკატორი აპლიკაცია და ტელეფონის ნომერი ახალ ტელეფონზე გადაიტანეთ და შეამოწმეთ, რომ იქიდან ანგარიშებში შესვლა შეგიძლიათ.
2. **Settings → Face ID & Passcode**-ში გამორთეთ **Stolen Device Protection**.
3. გახსენით **Settings**, დააჭირეთ თქვენს სახელს, ჩადით ქვემოთ და დააჭირეთ **Sign Out**-ს.
4. გადადით **Settings → General → Transfer or Reset iPhone → Erase All Content and Settings**-ში.

### Android {.android}

1. შექმენით ტელეფონის სარეზერვო ასლი. ავთენტიფიკატორი აპლიკაცია და ტელეფონის ნომერი ახალ ტელეფონზე გადაიტანეთ და შეამოწმეთ, რომ იქიდან ანგარიშებში შესვლა შეგიძლიათ.
2. Pixel-ზე გახსენით **Settings → System → Reset options → Erase all data (factory reset)**. Samsung-ზე გახსენით **Settings → General management → Reset → Factory data reset**.
3. ტელეფონი სწორედ პარამეტრებიდან გაასუფთავეთ. თუ სხვა გზით გაასუფთავებთ, ტელეფონი ახალ მფლობელს თქვენი Google-ის ანგარიშის მონაცემებს მოსთხოვს.

> [!tip]
> მეორადი ტელეფონი, რომელსაც ყიდულობთ, მისალმების ეკრანით უნდა ჩაირთოს. თუ სხვისი Apple Account-ის ან Google-ის ანგარიშის მონაცემებს ითხოვს, ტელეფონი ჯერ კიდევ გამყიდველის ანგარიშზეა მიბმული: ნუ იყიდით.
