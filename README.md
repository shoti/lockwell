# Lockwell

Short, step-by-step checklists that help you protect your accounts, phone and
conversations. No tracking, no ads, no cookies.

Website: [lockwell.org](https://lockwell.org/)

## Features

- **Checklists by topic.** Each step has a priority (essential, recommended,
  advanced) and instructions per device or app.
- **Articles** that explain in plain language why the steps matter.
- **In-browser tools**: password and PIN generator, link checker and cleaner,
  photo and document metadata viewer and remover, image redaction, a photo
  editor, hidden character detector, an email header analyzer, and a "what your
  browser reveals" check.
  Nothing is uploaded.
- **Private by design.** Progress is saved only in your browser, search runs
  on the page, and there are no third-party requests, enforced by a strict
  Content-Security-Policy and by tests.
- **Fast and accessible.** Static HTML that works without JavaScript, light and
  dark themes, WCAG 2.2 AA, printable.
- **No dependencies.** Plain HTML, CSS and JavaScript, built by a small Node
  script.

## Quick start

Requires Node.js 22 or later. There is nothing to install.

```sh
npm run dev     # http://localhost:4000, rebuilds on change
npm test        # run the tests
npm run check   # tests and production build into dist/
```

## Deployment

The site is hosted on Cloudflare Pages, which builds and deploys every push to
`main` with `npm run check` and publishes `dist/`. The build also writes
`dist/_headers`, so Cloudflare sends the security headers. GitHub Actions runs
the tests, a type check and the build on pull requests and on `main`.

## Check the privacy claims yourself

The site says it makes no requests to other sites, sets no cookies and saves
nothing until you act. You don't have to take that on trust:

- **Read the policy.** `dist/_headers` (generated by `src/build/assets.mjs`)
  sends a Content-Security-Policy that lets pages load only files from this
  site; `connect-src` is `'none'` everywhere except the browser check, which
  may call its own `/cdn-cgi/trace` when you press its IP button.
- **Run the audit.** `npm run audit` builds the site, then opens every page in
  a headless browser with a fresh profile (Chrome or Chromium, or Lightpanda)
  in light and dark mode. It fails on any request to another site, any cookie,
  any storage written without a click, any script error, and on more than one
  request when the IP button is pressed. It also checks links, page structure,
  mixed-script Georgian words, Georgian/English parity and the claims registry.
- **Check the live site.** In your browser's developer tools, the Network tab
  shows only `lockwell.org` requests, and Application → Storage shows nothing
  until you tick a step or pick a theme. The [privacy page](https://lockwell.org/en/privacy/)
  lists every saved value.

Time-sensitive facts (contacts, retention periods, dates) are listed in
`data/claims.json` with their source and when they were checked;
`npm run audit:claims` fails when one is overdue, and a weekly workflow checks
the claims and every outside link (`npm run audit:links`).
